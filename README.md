# OS Concepts Visual Simulator - Web Preview

هذه نسخة ويب تفاعلية من مشروع OS Concepts Visual Simulator، مبنية كمعاينة سريعة داخل المتصفح.

## التشغيل

افتح الملف التالي مباشرة في المتصفح:

- [index.html](index.html)

أو شغله عبر خادم محلي بسيط إذا رغبت:

```powershell
python -m http.server 8000
```

ثم افتح:

```text
http://localhost:8000/web/
```

## ماذا تحتوي

- Threads & Concurrency
- Processes & Parallelism
- Race Condition
- Mutex / Monitor
- Semaphore
- Producer / Consumer
- Deadlock
- Starvation

## ملاحظة

هذه النسخة للمعاينة الحية فقط، وليست بديلًا كاملًا عن تطبيق PyQt6 الأصلي الموجود في [obeed.py](../obeed.py).
